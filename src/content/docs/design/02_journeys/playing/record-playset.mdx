## Goal
Capture the exact expansions, variants, and scenario used for a match as a reusable
Playset, so the shared context of a match is fully reconstructable and does not need
to be configured again next time.

## Why
Raw scores tell you who won. Configuration data tells you why.
The same game played with different expansions, variants, or scenarios produces
a fundamentally different strategic context. Capturing that context turns a match
record into the basis for real insight — expansion impact, variant balance, scenario
difficulty — across hundreds of matches. Groups that play the same configuration
repeatedly only need to define it once and can reuse it every time.

## Outcome
- A reusable Playset now exists: expansions, variants, custom rules, and scenario.
- The Playset can be linked to this match and to any future match with the same configuration.
- Expansion and variant statistics become available for analysis.
- Matches linked to this Playset are reconstructable in full detail.
- Configuration data contributes to anonymous, aggregated community insights.
