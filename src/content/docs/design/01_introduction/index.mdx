This section outlines the logical progression of Stratastax:
from high-level intent to the domain model that defines the platform.

### Vision — Why?
The Vision explains the long-term purpose of Stratastax and the problems it aims to solve.
It describes the future the project is working towards and the role Stratastax plays within the tabletop gaming community.

### Concepts — What principles?
The Concepts describe the foundational ideas that make Stratastax unique.
They explain how gaming identities, privacy, data linking, ownership,
and the open ecosystem work together to form the platform.

### Domain Model — What?
The Domain Model defines the core entities of Stratastax and the relationships between them.
It provides the shared vocabulary used throughout the project and serves as the foundation
for the API, architecture, and implementation.
