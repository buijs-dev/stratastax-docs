## Goal
Connect a third-party application — a club tool, tournament platform,
companion app, or custom integration — to Stratastax via the documented
REST API.

## Why
Stratastax is a platform, not a closed application. Clubs, tournament
organizers, and developers building their own tools should be able to
participate without forcing their users to switch platforms. An open API
means the ecosystem grows beyond what Stratastax itself builds.

## Outcome
- The third-party application can read and write data within the access the user has granted.
- Data written via the API is fully integrated into the user's Personal Gaming Archive.
- The user retains ownership and can revoke access at any time.
- The application does not need to manage its own player identities — it participates in Stratastax's.
